# Turon Analytics - Простой сайт

Простой функциональный сайт без визуальных эффектов.

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

## Сборка

```bash
npm run build
```

## Деплой

### Вариант 1: Автоматический деплой (GitHub Actions)

1. Запушьте код в репозиторий:
```bash
git add .
git commit -m "Initial commit"
git push origin main
```

2. GitHub Actions автоматически соберет и задеплоит сайт на GitHub Pages
3. Сайт будет доступен по адресу: https://achilovraf.github.io/turon-analitics/

### Вариант 2: Ручной деплой

```bash
./deploy.sh
```

### Настройка GitHub Pages

1. Зайдите в Settings > Pages вашего репозитория
2. В разделе "Source" выберите ветку `gh-pages`
3. Нажмите Save
